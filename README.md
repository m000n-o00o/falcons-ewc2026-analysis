# Falcons Esports Benchmark

What separates winning teams from losing ones in Rocket League, and where does Team Falcons (Saudi Arabia) stand against the teams it faced at the Esports World Cup 2026?

A portfolio project by **Sarah** (data collection and analysis) and **Rahmah** (UX/UI and dashboard design). This repository contains the data pipeline and analysis. The dashboard is built separately on top of the exported tables.

## Dashboard

**[Open the interactive dashboard](https://m000n-o00o.github.io/falcons-ewc2026-analysis/dashboard/)**: results, tournament progression, winners vs losers, and Falcons vs each opponent. Designed by Rahmah; the web version reads the CSV files in `outputs/data_spec_exports/`.

## Scope (v1)

- **Game:** Rocket League, Esports World Cup 2026
- **Games analyzed:** all 23 games played by Team Falcons, from 5 series
- **Result:** Falcons won all 5 series and 18 of 23 games (goals 59-34), and won the title

| Stage | Opponent | Series |

| Group stage | R8 Esports | 3-1 |
| Group stage | Gentle Mates | 3-2 |

| Semi-final | Karmine Corp | 4-0 |

## Method

1. **Collect** player stats for every Falcons game from the Ballchasing API.
2. **Clean** the data (types, duplicates, missing values, team names).
3. **Derive** the winner of each game from goals, then average each team's 3 players into one row per team per game (46 rows: 23 winners, 23 losers).
4. **Compare** winners and losers on 12 metrics (boost, speed, positioning, saves, shots, demolitions) using a standardized difference:

   `effect_size = (winners mean - losers mean) / pooled std`

   With 23 vs 23 rows, a value of about 0.6 is needed to stand out from chance.
5. **Benchmark** Falcons' averages against each opponent.

## Findings

- No metric clearly separates winners from losers. The largest difference is 0.50 (time spent in the defensive third), below the ~0.6 reference.
- A weak pattern, treated as a hypothesis rather than a conclusion: winning teams spent more time in their own third and stole less boost.
- Shots are close to the outcome itself (goals come from shots), so they are not read as a cause of winning.

## Limitations

- **Selection bias:** only Falcons games were collected, so each opponent's figures (4-6 games) describe how it played against Falcons, not its general level.
- **Small sample:** 23 games, and only 5 Falcons losses.
- **Dependence:** games within the same series are not independent.
- **No significance test:** the 0.6 reference is approximate.

## Reproduce

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # add your Ballchasing API token
```

Then run the notebooks in order (01, 02, 03) from the `notebooks/` folder.
